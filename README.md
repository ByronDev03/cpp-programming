## Objetivos
- Practicar la programación en C++ mediante ejercicios.
- Fortalecer las habilidades de resolución de problemas y el pensamiento lógico.
- Comprender las estructuras de datos y los algoritmos fundamentales.
- Aprender los principios de la programación orientada a objetos.
- Explorar la programación genérica y la Biblioteca Estándar de C++ (STL).

## Tecnologías
- **Lenguaje:** C++.
- **Paradigmas:** programación procedimental, estructurada, orientada a objetos y genérica.
- **Herramientas:** cualquier compilador de C++, como GCC o Clang, o un entorno de desarrollo integrado (IDE) compatible con C++.

## ¿Cómo ejecutar los ejercicios?
1. Abre la carpeta con los ejercicios que deseas practicar.
2. Copia la solución de C++ en un archivo con extensión `.cpp`.
3. Compila el programa utilizando un compilador de C++.
4. Ejecuta el programa y pruébalo con diferentes datos de entrada.

Por ejemplo, utilizando [Dev-C++](https://sourceforge.net/projects/orwelldevcpp/) 

## Enfoque de aprendizaje
Los ejercicios están organizados siguiendo el mismo orden del curso, avanzando desde las operaciones básicas de entrada y salida hasta temas más avanzados, como estructuras de datos, algoritmos, herencia, polimorfismo, plantillas y la STL.
Se incluyen soluciones para facilitar la revisión de las implementaciones y comprender diferentes enfoques para resolver problemas de programación.
